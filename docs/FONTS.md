# Font attribution

This prototype self-hosts the Latin subsets of:

- **Outfit**, normal variable weight. Copyright 2021 The Outfit Project Authors. Source: https://github.com/Outfitio/Outfit-Fonts
- **Figtree**, normal and italic variable weight. Copyright 2022 The Figtree Project Authors. Source: https://github.com/erikdkennedy/figtree

Both use the SIL Open Font License, Version 1.1. Unmodified license copies are in `public/fonts/licenses/`.

The WOFF2 subsets were reused from the locally available, already self-hosted Google Fonts builds of the reference direction. Font family names and font data are unmodified. Font assets are not sold by themselves. No runtime Google Fonts connection is required.
